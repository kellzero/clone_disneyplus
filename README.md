# 🎬 Clone Disney+

Este é um projeto front-end que recria a interface do usuário da plataforma de streaming Disney+, desenvolvido como parte de um exercício de clonagem de interface e automação de tarefas.

## 🚀 Tecnologias Utilizadas

- **HTML5** (49%)
- **SCSS** (41%) - para estilização mais eficiente e organizada
- **JavaScript** (10%)
- **Gulp.js** - para automação de tarefas (minificação, otimização de imagens, etc.)
- **Uglify** - para compressão de arquivos JS

## ✨ Funcionalidades

- Layout responsivo inspirado no Disney+
- Estrutura HTML semântica
- Estilização com SCSS (pré-processador CSS)
- Automação de build com Gulp (incluindo minificação de JS com Uglify)
- Componentes interativos com JavaScript puro
